# 01. 코어 루프

## 범위
- 혼자, 농장 1개, 메모리 상태. 갈기 -> 심기 -> 물 -> 성장 -> 수확.
- DB·로그인·방문·채팅·상점 없음. 씨앗은 무제한으로 가정.

- 기존 코드에서 바꾸는 것:
    - 플레이어 충돌 제거 (같은 칸에 겹칠 수 있음)
    - 월드를 10*10으로 축소 (WORLD_MAX = 9). 밭은 그 안의 (2,2)~(7,7), 6\*6

## 칸 데이터
- 밭 한 칸이 기억해야 하는 값의 목록과 타입
    - state (uint8): 0 맨땅 / 1 갈린 땅 / 2 자라는 중 / 3 다 자람
    - crop (uint8): 작물 종류. 0 없음 / 1 순무 / 2 당근 / 3 호박
    - stage (uint8): 작물 성장 단계. 0부터 시작. 그 작물의 전체 단계 수에 도달하면 '다 자람'
    - watered_at (uint64): 마지막으로 물 준 서버 시각 (에포크 ms). 0이면 마름.
- 젖음/마름은 따로 저장하지 않고 watered_at으로 판단 (0 = 마름, 0 아님 = 젖음)
- 밭은 6\*6 2차원 배열 farm[y][x]. 인덱스 = y*6 + x. 밭 안에서의 좌표 = 월드 좌표 - 2

## 상태 전이
- 각 상태에서 어떤 행동이 허용되고, 하면 어떤 상태가 되는지

| 현재 상태 | 갈기 | 심기 | 물 | 수확 |
|---|---|---|---|---|
| 맨땅 | 갈린 땅 | 거부 | 거부 | 거부 |
| 갈린 땅 | 거부 | 자라는 중 (마름) | 거부 | 거부 |
| 자라는 중 (마름) | 거부 | 거부 | 자라는 중 (젖음) | 거부 |
| 자라는 중 (젖음) | 거부 | 거부 | 거부 | 거부 |
| 다 자람 | 거부 | 거부 | 거부 | 맨땅 |

- 자라는 중(젖음)은 행동이 아니라 시간 경과로 바뀐다.
- 단계 시간이 지나면 `stage + 1`하고 자라는 중 (마름)으로, 마지막 단계였으면 다 자람으로. (시간 계산 절)

## 시간 계산
- 칸의 단계는 시간이 지나도 서버가 바로 바꾸지 않는다.
- 그 칸의 값이 필요해지는 순간에 아래 '갱신'함수를 먼저 실행해서 현재 시각 기준으로 맞춘다.

- **갱신(칸, now)**:
    - 상태값이 [자라는 중], [젖어 있음], [물 준 지 단계 시간이 지났음]일 경우:
        - 한 단계 올린다
        - 마른 상태로 되돌린다 (watered_at = 0)
        - 마지막 단계에 도달했으면 상태를 [다 자람]으로 바꾼다
    - 아니면 아무것도 하지 않는다

- 부르는 시점: 그 칸에 대한 요청을 처리하기 직전 / 밭 전체를 클라에 보내기 직전
- 시각은 에포크 기준 ms (1970-01-01부터 지난 밀리초, uint64). watered_at == 0은 '마름'을 뜻함.
- 클라는 같은 계산을 표시용으로만 한다. 
    - 필요한 값: watered_at, 작물별 단계 시간, 서버 현재 시각.
- 서버 현재 시각은 PKT_FARM_SNAPSHOT에 실어 보낸다. 클라는 (서버 시각 - 자기 시계)를 기억해 두고, 이후 서버 시각이 필요하면 (자기 시계 + 그 차이)로 구한다.


## 패킷
- x, y는 월드 좌표 (0~9). 기존 PKT_TICK (1), PKT_SNAPSHOT (3)은 그대로.
- 클라 -> 서버
    - PKT_MOVE (2), payload 2byte: [dx: int8][dy: int8]
    - PKT_TILL (10), payload 2byte: [x: uint8][y: uint8]
    - PKT_PLANT (11), payload 3byte: [x: uint8][y: uint8][crop: uint8]
    - PKT_WATER (12), payload 2byte: [x: uint8][y: uint8]
    - PKT_HARVEST (13), payload 2byte: [x: uint8][y: uint8]
- 서버 -> 클라
    - PKT_TILE_UPDATE (20), payload 13byte: [x: uint8][y: uint8][state: uint8][crop: uint8][stage: uint8][watered_at: uint64]
        - 칸 하나의 현재 값. 칸이 바뀌었을 때, 그리고 요청을 거부했을 때 보낸다.
    - PKT_FARM_SNAPSHOT (21), payload 404byte: [server_now: uint64] + 36칸 * [state: uint8][crop: uint8][stage: uint8][watered_at: uint64]
        - 접속 직후 1회. 칸 순서는 인덱스 순 (y*6 + x)

## 서버 검증
- MOVE:
    1. payload 크기가 2가 아니면 무시
    2. dx, dy가 -1~1 범위를 벗어나면 무시
    3. 월드 경계를 넘으면 경계값으로 맞춤

- 갈기/심기/물/수확 (순서 공통):
    1. payload 크기가 맞지 않으면 무시 (심기 3, 나머지 2)
    2. x, y가 밭 영역 (2,2)~(7,7)을 벗어나면 무시. 심기는 crop이 1~3을 벗어나도 무시
    3. 내 위치와 (x, y)가 가로·세로 각각 1칸 이내가 아니면 거부
    4. 그 칸을 갱신 (시간 계산 절)
    5. 칸 상태가 아래 표의 '필요한 상태'가 아니면 거부
    6. 통과: 아래 표의 '적용'대로 칸을 바꾸고 `PKT_TILE_UPDATE` 전송

    | 행동 | 필요한 상태 | 적용 |
    |---|---|---|
    | 갈기 | 맨땅 | state = 갈린 땅 |
    | 심기 | 갈린 땅 | state = 자라는 중, crop 기록, stage = 0, watered_at = 0 |
    | 물 | 자라는 중 (마름) | watered_at = now |
    | 수확 | 다 자람 | 칸 초기화 (state = 맨땅, 나머지 0) |

    - 무시 = 아무 응답 없음 (형식이 틀린 요청)
    - 거부 = 그 칸의 현재 값을 PKT_TILE_UPDATE로 요청자에게 돌려준다. 클라 화면이 실제와 어긋나 있었다면 이것을 통해 바로 잡힌다.
