# 스코프 (MVP v1)

협동/소셜 멀티플레이 농사 게임. 코어 루프 하나를 작게 완성하는 것이 목표.

## 코어 루프
씨앗 구매 -> 밭 갈기 -> 심기 -> 물 주기 -> 성장 -> 수확 -> 판매

## 농장
- 계정당 농장 1개, 밭 36칸(6*6) 고정
- 칸 상태: 맨땅 -> (괭이질) -> 갈린 땅 -> (심기) -> 자라는 중 (단계, 젖음/마름) -> 다 자람 -> (수확) -> 맨땅
- 모든 칸은 맨땅으로 시작, 갈린 땅에만 심을 수 있음

## 작물
| 작물 | 씨앗 | 판매 | 단계 수 | 단계당 시간 | 최단 성장 |
|---|---|---|---|---|---|
| 순무 | 10G | 20G | 2 | 30s | 1m |
| 당근 | 30G | 75G | 3 | 60s | 3m |
| 호박 | 100G | 300G | 4 | 150s | 10m |

- 시간은 데모용 분 단위. 데이터 테이블로 분리해 교체 가능하게 함

## 성장·물 주기
- 물 1회 = 1단계 진행. 단계 시간이 지나면 다음 단계로 넘어가며 다시 마름
- 마른 동안은 성장 정지. 시듦·죽음 없음
- 서버는 물 준 시각만 저장하고, 단계 전환은 조회·행동 시점에 계산 (작물별 틱 없음, 오프라인 중에도 시간 경과)

## 서버 검증
- 행동(갈기·심기·물·수확)은 서버상 자기 위치에서 1칸 이내만 허용
- 상태 전이가 맞지 않는 요청은 거부 (젖은 칸·다 자란 칸·빈 칸에 물 주기 등)
- 같은 칸에 동시 요청이 오면 먼저 도착한 쪽만 성공

## 방문·채팅
- 유저 목록에서 골라 방문. 주인이 오프라인이어도 방문 가능
- 농장 = 방. 첫 입장 시 DB에서 로드, 아무도 없으면 언로드
- 방문자: 이동, 마른 작물에 물 주기(1회당 +2G), 채팅. 갈기·심기·수확은 주인만
- 농장당 동시 8명, 한 사람은 한 번에 한 농장에만 있음
- 채팅은 같은 농장 안에서만 (전체 채팅·귓속말·기록 저장 없음)

## 경제·계정
- 시작 자금 100G
- 상점은 메뉴 창으로만 제공: 씨앗 구매, 작물 판매(즉시 정산)
- 인벤토리는 종류별 개수만
- 닉네임 + 비밀번호 최소 로그인

## 저장
- 계정, 코인, 인벤토리, 농장 칸
- 서버 재시작 후에도 유지

## 컷 (MVP 이후)
계절·하루 주기·날씨, 비료·물 리필, 시듦, 동물·광산·낚시·NPC·전투·퀘스트, 친구 시스템, 농장 확장·꾸미기, 거래·선물, 랭킹, 공용 마을 맵

## 완료 기준
1. A가 씨앗 구매 -> 갈기 -> 심기 -> 물 -> 성장 -> 수확 -> 판매까지 한 바퀴
2. B가 A 농장 방문 -> 서로 이동이 보임 -> B가 물을 주면 A 화면에 즉시 반영 -> 채팅
3. A가 로그아웃한 동안 B가 물을 줌 -> A 재접속 시 자라 있음
4. 서버 재시작 후에도 전부 유지

## 기술
- 서버: C++17 / Linux epoll
- 프로토콜: TCP 바이너리
- 클라이언트: Unity (placeholder 먼저)
- DB: 미정

## 구현 순서
조각마다 상태·패킷·검증 규칙을 반 페이지로 먼저 적고 구현.
1. 코어 루프 (혼자, 농장 1개, 메모리 상태, 콘솔 클라)
2. 상점·인벤토리·코인
3. 방 + 방문 + 방 안 이동 동기화 + 채팅
4. Unity placeholder 클라 -> 디자이너 애셋 리스트
5. DB 저장 + 로그인 (DB 호출은 워커 스레드로 분리)
6. 주인 오프라인 농장 방문 (DB 로드/언로드)
7. 봇 테스트, README, 데모 영상
